# Search and subscribe

Have a search option that allows the user to search for other users. Upon clicking search, a list of matching users show up with the option to subscribe to that user's posts. Upon clicking subscribe(or unsubscribe), the feed has to reflect the latest subscription(unsubscription). Subscription should show the subscribed user's posts and unsubscribe should remove those.

The delete option should only show up on the user's own posts.
